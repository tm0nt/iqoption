# Localisation — Avalon auth clone

The source site is multi-locale: its header language menu offers **English, Español and
Português**, and every page exists under a matching path prefix. The clone reproduces that
structure rather than hard-coding English.

## Where the strings came from

Every string in `src/i18n/avalon.ts` was read from the corresponding live page —
`trade.avalonbroker.com/{en,es,pt}/{login,register,change-password}` — via `getComputedStyle`-era
DOM extraction. Nothing was machine-translated, so the clone reads exactly like the original in
each locale, including the site's own quirks:

- The English cookie notice uses curly quotes (`“Got it”`); the Portuguese one uses straight
  quotes (`"Entendi"`).
- The Portuguese recovery instruction has no trailing period.
- The register auth link has a trailing word in English and Portuguese (`now` / `agora`) but a
  different sentence shape in Spanish — so the link row is stored as lead / link / tail per
  locale rather than as a template.
- The terms sentence is stored as four plain-text segments interleaved with three links,
  because Portuguese inserts articles around the link text ("a Política de Privacidade").

## Country and dial-code lists

Both register selects are localised **and re-sorted** per locale (Spanish and Portuguese put
"Alemania"/"Alemanha" third, where English has "Algeria"). `shared/countries.ts` stores:

- an English baseline (35 countries, 241 dial codes),
- the exact ISO display order per locale,
- only the names that differ from English.

`localizedCountries(locale)` and `localizedDialCodes(locale)` rebuild the list the site serves.
The Portuguese list keeps several Spanish spellings on the live site (e.g. "Camerún", "Kenia");
those are reproduced as served rather than corrected, since this is a clone.

## Adding a locale

1. Add the code to `LOCALES` and `LOCALE_LABELS` in `src/i18n/avalon.ts`.
2. Add a dictionary entry matching the `AvalonDictionary` contract.
3. Add a flag icon to the sprite in `shared/icons.tsx` and map it in `shared/LanguageMenu.tsx`.
4. Add the locale's ISO ordering and name overrides to `shared/countries.ts`.

`generateStaticParams` and the language menu pick the new locale up automatically.
